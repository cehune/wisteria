# wisteria renderer

This is a GPU accelerated, Metal based renderer designed as a baseline to practice sota rendering methods in both pathtracing and real time rendering.
My current focus is in path tracing, but this renderer offers real time camera control, switching between path tracing and rasterization, and headless options for just printing out images.
